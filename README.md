Проект Mesto-finel-2

В проекте можно добавлять и удалять карточки, менять аватарку профиля, а так же имя пользователя и занятие. Так же можно посмотреть статистику сайта, нажав на иконку.

Ссылка на проект:
https://varvarapiunova.github.io/mesto-finel-2/

Команды запуска проекта:
npm install
npm run dev

Команда сборки проекта:
npm run build
