Проект Mesto

Это учебный проект ассоциированных программ Яндекса и СГУ.

Проект является интерактивным сервисом, в котором добавлять и удалять свои карточки, менять аватарку профиля, а так же имя пользователя и занятие. Так же можно посмотреть статистику сайта, нажав на иконку. В проекте присутсвует валидация форм.

Ссылка на проект:
https://varvarapiunova.github.io/mesto-finel-2/

Команда установки зависимостей:
npm install

Команда запуска локального сервера разработки:
npm run dev

Команда сборки проекта:
npm run build

Команда публикации собранного проекта на GitHub Pages:
npm run deploy
